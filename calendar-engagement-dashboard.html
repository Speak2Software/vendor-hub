📋 Action Plan by Segment

Use these talk tracks when reaching out to each segment

Service Calendar Users

Already using the advanced calendar — focus on depth of features

1
Review signage adoption — Many have events but zero signage checked. Walk them through how to enable digital signage display.
2
Push announcements feature — Communities with no announcements are missing a key engagement tool. Demo how announcements drive attendance.
3
Enable RSVP / attendance tracking — Communities without registration/attendance data can't measure ROI. Help them turn this on.
4
Share best-practice benchmarks — Show them how top performers (mather-tysons, atlas-legacy-fairview) are using the platform.

Simple Calendar Users

Using basic calendar only — opportunity to upgrade engagement

1
Understand why they chose Simple — Ask if it was a deliberate choice or just what they set up first. Many may not know Service calendars exist.
2
Demo the Service calendar upgrade path — Show them signage, announcements, RSVP, and attendance tracking as features they're missing.
3
Offer migration assistance — Removing friction for the switchover is key. Offer a 30-min setup call.
4
Note: Juniper group has 10+ communities on Simple. A single group conversation could unlock a bulk upgrade.

Not Using Calendar

Zero activity — re-engagement and onboarding priority

1
Audit if account is live — Some entries may be test/corp accounts. Confirm which are real communities with staff.
2
Identify the blocker — Is it a training gap? Staff turnover? Technical issue? A 15-minute check-in call will surface the real reason.
3
Send a "Quick Win" onboarding email — Share a 3-step setup guide. Low-lift tasks drive activation. Offer a live screen-share session.
4
Set a 30-day follow-up — If still zero after outreach, escalate to customer success or account manager review.
